Hospital Treatment Cost Predictor

A Random Forest model that predicts a patient's treatment cost, with a Streamlit app to try it.

Situation

A hospital operations dataset with 100,000 records and 15 columns, containing missing values and impossible values (for example ages above 100).

Task

Predict Treatment_Cost_USD from patient and admission details, and prove the model works on data it has never seen.

Action

  • Turned out-of-range values into nulls using fixed bounds.
  • Split 80/20 first, then fitted imputers, encoders and scalers on the training set only, so nothing leaked from the test set (30 features).
  • Trained Linear Regression, Decision Tree, SVR and Random Forest.
  • Saved the model with all preprocessing in one file, and built a Streamlit app plus an offline Windows version.

Result

On 20,000 unseen test rows the final Random Forest reached R² 0.8626 with an average error of about $1,426. Length of stay is the strongest cost driver in the data.
